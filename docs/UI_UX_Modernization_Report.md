# Vizly 现代 B2B 架构交互与 UI/UX 体验重构报告

**文档版本**: v1.1
**核心目标**: 彻底摒弃传统“中后台包围式边框”的旧观念，将全局体验拉升至符合 2026 甚至下一代的次世代协同白板水准（参考行业标杆：Figma, Spline, Miro）。

在这长达多个版本的跨越式迭代中，我们针对整体 UI 面板、底层画布自适应引擎以及各个特定图表域插件，开展了大规模的系统级升级。本报告详细记载了视觉规范及关键的工程架构方案。

---

## 0. 行业前沿 B2B 设计最佳实践调研

在真正动刀重构之前，团队对当今主流的下一代设计工具与复杂 B2B 软件进行了深入拆解，提炼出以下四大核心设计趋势（这也是支撑我们全面重构的源动力）：

### 0.1 Spline / Framer：无边框与绝对画幅掌控
- **痛点**：传统工作流软件（如老版 Jira、Confluence）常常被厚重的多级导航栏蚕食了 30% 以上的屏幕核心生产区域。
- **先进做法**：像 Spline 和 Framer 已经基本抛弃了“顶栏-侧栏”的正交排版。它们让 3D 或 2D 画布占据 `100vw × 100vh` 的绝对可视区域，所有的控制面板均以“漂浮小岛（Floating Panels）”形式存在，极大缓解了设计师的视野逼仄感。

### 0.2 Miro / FigJam：白板协同的心流保护
- **痛点**：当用户在无限放大的白板中工作时，原生滚动条和硬切断的面板边缘会让坐标感知中断。
- **先进做法**：去除原生浏览器的滚动机制，依靠全鼠标中键拉拽、右下角迷你地图（MiniMap）加上防干涉悬浮工具块，保障用户“在无限宇宙中穿梭”的流畅心流（Flow State）。

### 0.3 Arc Browser / Linear：高透毛玻璃与环境感知
- **痛点**：纯不透明度（Opacity）会在内容交叠时导致对比度不足，文字难以阅读。
- **先进做法**：大量采用 `backdrop-filter: blur(x)` 技术。背景呈现半透明以维持空间的三维层次感，同时强力的模糊滤镜保障悬浮层上的图标和字体享有顶级的对比度（WCAG 标准），这已经成为了“高级感”的代名词。



### 0.4 Figma：面板收纳与极简主义交互
- **痛点**：工具按钮过多导致的认知过载。
- **先进做法**：利用 Contextual Toolbar（上下文工具栏）。在默认状态下，顶部只保留最薄的控制轨；只有当选中特定节点或连线时，智能弹出的 Property UI 才会在光标附近或侧边抽屉动态激活，实现零干扰（Zero-clutter）设计。

## 1. 核心视觉规范与范式转移 (Paradigm Shift)

在早期的设计中，应用使用了大量实色、绝对割裂的布局（左侧原生 Sidebar，顶部实色 Navbar），这些对于一款空间画布编辑器来说造成了严重的“幽闭感”。基于上述调研，我们完成了彻底的翻新。

### 1.1 从区块堆叠到全画幅沉浸 (Immersive Floating Layout)
*   **解构实心面板**：将以往固定在左右侧的实心抽屉/侧边栏，全部拆解并替换为依附在屏幕周围的**浮动控制岛 (Floating Islands)**。
*   **无边画布投射**：最底层的 React Flow 画布 (及其所属的 Background 网格) 被赋予全屏级别的主宰权。这种 `100vw × 100vh` 的底层映射，在物理空间上无限拉升了用户的作图边际。

### 1.2 高级折射材质 (Glassmorphism System)
我们全面重构了顶层 UI 层级（`.canvas-ui-layer`），不仅限于简单的半透明 `opacity`：
*   **毛玻璃滤镜**：广泛应用了 `backdrop-filter: blur(16px) saturate(180%)` 处理。
*   **物理层级阴影与抗频闪**：使用多层次的 `box-shadow: 0 4px 24px rgba(0,0,0,0.06), 0 1px 3px rgba(0,0,0,0.02)`，配合 `1px solid rgba(255,255,255,0.4)`(透闪边框) 压住玻璃面板的边缘粗糙度，呈现媲美 macOS 的精细质感。

## 2. 深度架构优化与工程解耦

### 2.1 编排剥离引擎：UnifiedDesigner 降临
旧版的 `FlowchartDesigner` 承载了长达两千行的“大泥球”代码，我们将这套架构正式升级：
*   我们将基础工作区包装成了无状态物理壳 **`FlowchartCanvasShell`**。
*   所有业务交互、AI 对话面板和快捷面板，提纯到了顶层 **`UnifiedDesigner`**。
*   这带来了一个立竿见影的好处：不管是 `Flowchart`、`MindMap` 还是 `Architecture` 图标引擎，均可无缝嵌入这个现代化 UI 标准壳。

### 2.2 防干扰缩放机制 (CSS Zoom vs Semantic Matrix)
*   由于我们在外部容器支持手动 `zoom (uiScale)` 调整功能，React Flow 自身对于设备 DPI 坐标系的内置计算会全部失效、拖拽位移会加倍或变慢。
*   **注入逆向仿射变换 (Counter-Zoom Compensation)**：在底层 DOM 给 React Flow 挂载了 `zoom: 1 / uiScale` 或针对坐标系数目重定位。保证在物理视口和业务视口的拖拽比率绝对锁定为 `1:1`，避免了灾难性的交互滑移和卡顿现象。

### 2.3 Dashboard 与控制台重塑 (Console Topnav)
*   除图表编辑器本身，我们将文件管理台（Dashboard）亦做了现代化重构。
*   废除左侧导航结构，引入基于顶层路由导航 (Top Navbar) 的设计。释放横向宽度，大幅改善多列数据预览以及缩略图的视觉占比。

## 3. 破局难点：安全区导航与避障引擎 (Safe Zone Layout Engine)

这是本次最关键的深层数学重构。因为 UI 改为“悬浮”，底层全屏，这就意味着：**自动填充视口（FitView）会让图形直接钻进悬浮岛下方，形成死角盲区**。

为彻底根治这一痛点，我们开发了专门的“安全避让体系 (Safe Zone)”：

### 3.1 定义坐标红线 (Absolute Safe Padding)
我们显式地在前端计算库中提取了常数区：
```typescript
const SAFE_TOP = 64;   // 顶部全局工具环的最高物理高度
const SAFE_LEFT = 56;  // 左侧原子化工具栏的物理宽度
```

### 3.2 深度挟持与重写 React Flow FitView
由于官方 `fitView()` 并不知道咱们外部罩了浮动层 UI，它永远基于左上角 `(0,0)` 结算数学坐标轴。我们通过 `DiagramControlBridge` 和底层包装件主动废弃了官方调用，自行掌控视口生命周期：
*   **Bounding Box 计算预留外延**：不仅仅计算节点尺寸，连较粗的**线条 (StrokeThickness)** 和**智能绕线 (Smart Orthogonal Padding)** 引发的高低落差也全部纳入自适应外延。
*   **计算着陆点：精准迫降**：在计算全局缩放和原点对准时，算子直接注入了 SAFE 变量偏移量：
    ```typescript
    const x = SAFE_LEFT + padding - (minXBound * zoom);
    const y = SAFE_TOP + padding - (minYBound * zoom);
    ```
*   这保证了：哪怕图形极度狭小或是巨幕，初始化进入该存档或双击自动居中时，**图形最高和最靠左的元素必定稳稳悬停在浮岛下方 16px 处**，视觉避让分毫不差。

### 3.3 画布标尺解构与重绘 (Canvas Ruler Defect Fix)
由于原生的 HTML `<svg>` 节点标准并不允许动态在 `width/height` 数值上直接挂接 CSS 变量或 `calc(100% - x px)`，这导致前版悬浮避让时，标尺坐标域渲染直接崩溃消失。
*   **修正渲染流**：我们将 SVG 拉起为全屏 100%，但在其内部的轨道绘制 (`<rect>`) 以及虚线阵列逻辑中，手动利用 `.filter()` 剔除了物理上会被 SAFE_ZONE 盖住的废弃刻度线。
*   这不仅修复了图纸的缺失，同时免去了渲染冗余DOM，性能更优。

### 3.4 “首次创建”生命坐标修正
*   对于尚未建立历史快照包围盒的新建图纸（比如全新思维导图），过去节点均在 `(x:-60, y:-30)` 等反向象限建立。
*   为了配合现代浮窗，我们在 `useFlowchartState` 基础常数中，将首发节点修改定锚在坐标系正象限的焦点（例如 `(x:260, y:160)`）。这意味着就算没有任何重计算，初生点就已经位于视口的最清爽安全区域。

## 4. 交付与展望

在 2026 前端白板架构演进的视角下，我们不仅停留在 UI 改色，更是彻底改造了底层的**事件、空间引擎和模块复用性**。
1. **多端自适应预留**：目前的 Safe Zone 参数可通过 React Context 进行媒体查询下发，这意味着随时可以无损过度至移动设备端。
2. **极速交互心智**：不论从控制台打开复杂云端架构，或是本地拖拽组件，底层不再具有僵直感和遮挡感。
这些底层基建将保证在接下来引入更多高阶组件生态（诸如 3D 节点池/高级智能网格策略）时，地基坚不可摧。
