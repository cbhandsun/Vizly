# 启动证据与增量编辑基准

## 范围与运行方式

本轮只修改浏览器验证工具，不调整生产布局、路由算法或性能预算。

先执行 `npm run build`，使用 `vite preview` 提供当前 `dist`，然后设置
`PRECOMPILED_ROUTE_BASE_URL` 为该预览地址，执行
`npm run benchmark:display-routing-browser`。默认 30 次采样；
`DISPLAY_ROUTING_SAMPLE_COUNT` 可选择 1–100 次。每次分别打开物流图，拖动
`tms`、`wms`、`l-oms`，每个拖动沿图坐标移动 `(40, 12)`。

原有性能、端点、障碍物和绘制门禁继续生效。新增 `editStability`
输出每个指标的 min、max、mean 和 p95；样本缺失或非法时直接失败。
这些是结构观测指标，尚未设置质量阈值，不能把完成采样等同于稳定性达标。

## 指标口径

- 节点比较使用编辑前后都存在、且未被显式编辑的节点。父子局部坐标先解析为
  绝对图坐标；父容器移动引起的后代移动也会计入。位移单位为图坐标像素，
  与视口平移和缩放无关。超过 0.01 才计为移动；总量和最大值保留真实数值。
- 无关连线指两端均不属于显式编辑节点的保留连线，**不等于**路由器的
  mutable/context 集合。因障碍物变化而重路由的非关联连线仍计入指标。
- `changedPortCount` 是端口发生变化的连线数，每条线最多计一次。
- `changedPathCount` 比较已提交 Worker 路由的点序列，点数变化或任一点位移
  超过 0.01 即计数。共线分段改变也会计入；它不是曲线形状等价判定。
- `changedGeometryCount` 在上述变化中，再移除完全重复点与同向共线分段后比较。
  保留折返、绕行和方向变化；不等同于任意曲线的形状距离。仍使用 0.01 的点位容差，
  不扩大原始点序列的变化集合。旧报告缺少该字段表示未采集，不能填零参与新汇总。
- 路径长度为无关连线折线段欧氏长度之和；拐点忽略重复零长度点，并计入反向折返。
  不统计最终 SVG 桥接装饰长度；最终绘制安全仍由原有 DOM 审计负责。
- 增删节点、增删连线和同 ID 连线改接分别计数，不混入保留结构的比较。
  本轮真实浏览器场景覆盖拖动；增删口径有单测，尚未扩展为浏览器增删操作矩阵。
- 基准快照只在验证页面内暂存必要几何字段。外部报告只保留数字，不输出标签、
  节点 ID、端口名、坐标序列或用户内容。

## 启动异常证据

预注入探针记录 DOM 就绪、页面 load、首个 root 子元素、Worker 构造、首个带
requestId 的消息发送尝试、首个匹配消息形态的响应、首个非空路径出现的时间。
这些是相对于探针安装的首次观测时间，不是各阶段独占耗时；Worker 构造不代表
Worker 已就绪，收到响应也可能是进度消息。`null` 表示未观察到，不解释为零。

等待失败报告包含这些时间、页面状态、错误计数、白名单路由状态和最多 16 条
请求/响应摘要。浏览器求值受原等待预算约束，诊断读取另有最多 1 秒预算。
求值异常和卡死分别标为 `evaluation-failed` 与 `evaluation-timeout`，不回显
CDP 原始异常。该修复防止等待器自身无限等待，未证明历史偶发空白的根因。

## 后续扩展

拓扑矩阵的 `outsideRequestedRoutingGroup` 与 `observedRequestedMutableEdgeCount`
明确指请求发出时的连线组。旧报告中的 `outsideRoutingGroup` /
`observedMutableEdgeCount` 使用同一比较集合，历史记录需按提交区分字段。
Worker 的容器恢复可以扩大到相邻连线，完整回退可以重算全图；因此请求组外
发生路径变化，不足以证明越过最终事务边界。显式编辑意图的 `intent` 指标仍
保留这些变化。新增响应 `eligibleEdgeIds` 记录增量候选交给最终修复器的允许集合，
来自实际决策，不从变化路径反推；它不代表所有刚性随动对象或全图优化范围。
协议限制唯一 ID 数量和长度、要求 ID 属于最终连线，只允许 hard-clean 的
incremental-route / fallback none 响应携带，传输为 patches 时保持该证据。

浏览器报告新增 `finalRepairScope`：`available` 时提供集合数量、可见比较数量和
`outsideFinalRepairGroup` 指标；缺失为 `unavailable`，全量回退为 `full-route`，
两者不能伪装成空集合或零变化。报告仅导出计数和指标，不导出连线 ID。
请求组外变化仍保留，不能仅凭连线被纳入最终修复集合就认定其路径变化必需。
当前拓扑矩阵要求最终集合证据存在或明确全量回退；路径变化必要性另行实验。

采集更多图规模、嵌套与密度样本后再制定阈值。优先扩展真实增删、固定端口、
连续拖动与撤销重做，分别比较节点移动、端口变化、路径变化与长度增长。
