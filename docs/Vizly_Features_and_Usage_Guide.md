# Vizly 进阶特性与使用技巧指南

随着近期架构与体验的重大升级，Vizly 不仅强化了底层性能，还为专业团队加入了多项企业级新特性。本指南将帮助您快速了解并掌握 Vizly 的最新核心功能。

---

## 🚀 一、实时协作：丝滑如原生的联机体验

### 1.1 开启分享与协作
在画布右上角的工具栏中，点击 **[分享与协作]** 按钮。
- **状态指示灯**：按钮旁现在配备了智能连接指示灯。
  - 🟢 **翠绿色**：已成功连接至远端房间，可安全进行多人画图。
  - 🟠 **琥珀色**：正在握手与重连中。
  - 🔴 **红色**：断开连接。
- **协同房间分配**：系统会自动为您当前画板分配一枚特定的协同 ID，您只需把带有 `?room=xxx` 的链接发给同事，即可同频操作。

### 1.2 高性能同步反馈
得益于全新架构（基于引用的差异更新器和原生 `requestAnimationFrame` 追踪引擎），现在的协同即便在包含超过数百节点的拓扑图中进行多目标框选和极速拖动，也不再发生页面卡顿。您和同事的鼠标指针现在均表现为 **60帧平滑追随**。

## 📦 二、时光机：无缝版本追踪 (Version History)

### 2.1 捕获与保存您的灵感
在右上角找到新的 **[时钟图案] 版本历史** 抽屉开关。
当您完成了架构设计的重要节点时：
1. 点击右上角时钟图标，打开右侧抽屉。
2. 在抽屉内输入您的里程碑描述（例如："V2 数据库模型确认版" 或 "初始泳道划定"）。
3. 点击保存，系统即会瞬间摄录一份不可变的快照。

### 2.2 快照恢复与无感云回退
- 您的每个快照都会在右侧栏以精致的“时光轴”卡片呈现，并带有准确的时间戳。
- **混合容灾存储**：系统默认会向云端（Supabase）写入快照，如遇无网络环境，系统会自动向您的浏览器 IndexedDB 本地数据库透明写入，保障数据绝不丢失。
- **双击回溯**：在您的历史列表中，只需点击任一版本卡片上的 **[恢复]** 按钮，系统会无缝抹平当前杂乱的草稿，将整个拓扑设计精准带回彼时的清爽状态。

## 🎨 三、专深业务组件：泳道图与 ER 视图

### 3.1 跨职能协作流（Swimlane / 泳道图）
在左侧组件库寻找“基础容器” -> 单击拖入画板：
- **拖拽绑定**：您可以直接将流程卡片拖拽进入某个横向泳道框（例如：财务部、研发部）。卡片便会自动被包裹，随着外部的泳道模块一起移动。
- **背景层隔离**：泳道组件使用了专门的负值 Z-index 系统，它永远不会挡住内部的重要卡片连线。您可以放心地将它拉成一个大舞台，而不必担心误触核心流程的边框。

### 3.2 数据结构设计大师（ER 表图）
现在 Vizly 支持标准的后端数据建模：
1. 从左侧拖入“数据库表 / ER 表”节点。
2. 点击节点即可通过侧边栏（右侧属性面板）直观地对数据列（Columns）进行增改。
3. **数据列支持类型与主键**：您可以将某字段标记为 `Primary Key`，也能自定义字段的数据类型（如：INT、VARCHAR）。
4. **视觉规范**：表头会以深色醒目提示您的实体名称，字段将以高对比度的列表逐行显示，为后端同事生成截图时，再也不需要去写手绘框了。

## ⚙️ 四、化繁为简：现代配置面板

我们重新整合了全局配置（Configuration Panel）选项。去除了诸如多轴、不稳定的寻路算法等冗余开关，确保您接触到的皆为生产可用配置。
- **快速路由**：如今默认的线条均采用稳定的高性能寻路逻辑（A* 优化与防遮挡）。如果您发现连线穿过了节点主体，打开全局配置勾选 **[防阻挡路由]**（Obstacle Avoidance）即可体验智慧的自动绕行路线。
- **网格与磁吸**：您依然能在选项里调整吸附阈值，但在新版引擎的融合下，自动对齐能力更敏锐也更少阻力。

## 🚀 五、极致性能：200+ 节点大型架构审计

Vizly 现已完成针对超大规模架构图的底层性能调优。
- **200+ 节点稳态交互**：经过严格压力测试，即使在包含 200 个复杂业务节点及 300+ 连线的情况下，画布依然保持 **60 FPS** 的响应速度。
- **TTI (Time to Interactive) 优化**：秒级加载体验，复杂架构瞬间就绪。
- **高性能模式**：系统内置智能启发式算法。在执行大规模拖拽、布局切换或缩放时，会自动进入“高性能模式”，通过减少非必要的 CSS 滤镜与阴影开销，优先保障操作的丝滑感。

## 🧠 五、脑图插件突破：进阶思维导图引擎

在最新的版本中，MindMap 插件迎来了对齐业内顶尖标准（如 XMind / 飞书思维笔记）的史诗强化。
- **键盘极速输入**：在选中任意节点时，按下 `Tab` 键即可瞬间生成子节点并光标自动聚焦；按下 `Enter` 键即可在同级追加兄弟节点。您的创作过程将不再需要鼠标干预。
- **动态结构变形 (Top-to-Bottom / Fishbone 等)**：在底部悬浮工具栏中，点击【更改方向】选项，您不仅可以选择左、右生长，亦可一键让整个思维导图垂向演化（自上而下），所有连线与加减按钮将自动寻找对应的解剖学贴合点。
- **分支色相律动 (Auto-Coloring)**：从中心主题发散出的每一根根大枝蔓现在都具备“色彩继承”能力。系统会通过内置的调色盘色相轮，智能均匀地给各分支持续灌注统一、协调的设计感颜色。
- **折叠树形收纳**：遇到拥有大量叶子节点的重型议题？轻点节点尾部的 `[ - ]` 把手即可瞬间折叠分支，该节点会自动生成徽章告诉您隐藏了多少层级，并且引擎将自适应平滑聚合树的结构布局。

### 5.2 AI 极致交互与效率飞跃（第四阶段升级）
- **AI 演讲提词器 (Speaker Notes)**：全屏演示模式下的半透明磨砂玻璃提词背板。切换节点时通过 400ms 防抖请求大模型生成当前节点的演讲稿，支持一键重新生成和切换不同语气风格（商务专业、幽默风趣、通俗易懂、严谨学术）。
- **AI 关系线语义解释 (Smart Connectors)**：在创建关联线时拦截并显示 `...` 加载动画，AI 自动分析起点和终点节点主题之间的语义关联，一键打标至连线并支持 multiplayer 同步。
- **AI 敏捷任务看板 (Storm-to-Agile Kanban)**：一键扫描提取思维导图最底层的叶子执行节点卡片。支持拖拽与勾选分类（待办 / 进行中 / 已完成），状态双向同步回脑图 Tags。提供 AI 一键智能敏捷规划和 Markdown 格式看板导出。

## ⚡ 六、键盘即力量：Command Palette (⌘K) 全局命令面板

我们将 Figma / Linear 被广泛称赞的极速交互范式引入了 Vizly 画布：
- **触发与唤起**：随时按下键盘 `Ctrl + K` (Windows) 或 `Cmd + K` (Mac)，即可呼出通透的玻璃态搜索框。
- **意图直达**：输入“导出”、“排列”、“主题”或者是各类组件节点名，方向键选中后 `Enter`，命令触达即刻生效。真正让您省去了满屏幕寻找菜单的机械成本。

## 🤖 七、AI 绘图副驾 (AI Design Pilot)

我们打通了“对话”到“绘图”的最后一公里，AI 现在可以直接感知并修改您的画布。

### 7.1 原子化指令操作
您可以在 AI 聊天框中直接输入如下意图：
- **增点**：“帮我在网关后面加一个缓存数据库” -> AI 将自动匹配 `architectureNode` 类型并调用 `database` 形状。
- **连线**：“把 A 连到 B，标签叫‘查询请求’” -> 自动寻找匹配节点 ID 并建立逻辑连接。
- **动态模拟**：“模拟下 A 到 B 的流量” -> 自动调用 `/flow` 原子指令，产生实时的路径呼吸发光动效。
- **审美方案**：“给我一套深色的专业配色方案” -> 调用 `/style` 指令一键切换 CSS 变量主题。
- **一键展示**：“进入汇报演示模式” -> 调用 `/present` 指令隐藏侧边栏并进入全屏。
- **清空/删除**：“删掉所有断开连接的节点”。
- **布局调整**：“帮我把现在的图按树形重新排列”。

### 7.2 智能嵌套识别
当您在架构模式下要求增加组件时，AI 会尝试理解组件的系统归属。如果您已经创建了“数据中心”容器，新增的数据库节点将**自动定位并放入容器内部**，且容器会自动扩展尺寸以确保整洁。

## 🔍 八、架构师审计 (Architecture Linter)

不仅仅是画图，Vizly 还关注架构的专业性。

### 8.1 运行审计
使用 `/analyze` 命令，AI 会结合底层的 Linter 引擎输出深度报告：
- **循环依赖检测**：精准识别服务调用链路中的闭环，预防死锁隐患。
- **层级合规性检查**：基于 `domainClass` (用户端/接入层/业务层/数据层)，自动拦截逆向调用或非法跨层调用。
- **孤岛检测**：标记那些悬空、未定义的逻辑组件。

### 8.2 一键修复建议
分析报告中会包含具体的 `[COMMAND: ...]` 修复指令，您可以根据建议点击或确认，让 AI 帮您一键修正架构缺陷。

## 🎬 十、演示与动效：专业汇报利器

### 10.1 沉浸式演示模式 (Presentation Mode)
在顶层栏点击演示图标或通过 AI 输入 `/present`：
- **UI 零干扰**：系统会自动折叠侧边栏、菜单栏与工具栏，只保留纯净的画布。
- **全屏专注**：自动触发浏览器全屏，让您的架构方案占据整个视野。
- **安全锁定**：在演示模式下，画布默认进入只读保护，防止汇报过程中的误触。

### 10.2 触觉交互反馈 (Tactile Design)
Vizly 引入了基于弹簧物理特性的 **触觉反馈系统**，让图表操作更具真实感：
- **节点 Pop 效果**：鼠标悬入节点时，会有细腻的向上浮动与投影加深效果。
- **连线选中反馈**：选中的连线会产生动态的宽度跳变动画，极大增强了操作的掌控感。
- **丝滑过渡**：所有 UI 容器（如属性面板）的呼出与折叠均采用 `cubic-bezier` 高阶缓动曲线。

## 👔 十一、专业建模：UML 时序图 (Sequence Diagram)

Vizly 现在支持原生的 **UML 时序图** 绘制，完美兼顾灵活性与约束性：
- **生命线 (Lifelines)**：支持 `Actor`、`System` 等多种参与者类型。
- **智能连接**：消息线会自动在生命线之间磁吸。
- **一键对齐**：通过顶部的 **[时序图工具栏]**，可以一键让所有参与者在 X 轴均匀排布。
- **高性能渲染**：得益于虚拟化技术，即便拥有数十条交互线的复杂时序逻辑也能保持流畅缩放。

## 📖 十二、文档化协作：自动化文档生成 (Doc-Gen)

我们将“画图”与“文档”真正打通：
- **一键生成概览**：点击 **[导出] -> [导出为 Markdown 文档]**。
- **智能分析集成**：导出的文档会自动包含一份“架构健康报告”，识别潜在的孤岛节点或资源冗余。
- **自动分层描述**：文档会根据您的 `Domain Class` 定义，自动将节点划分为“接入层”、“业务层”、“数据层”进行分类表格描述。
- **交互细节保留**：所有的连线关系与备注信息都会被转化为结构化的列表，方便复制到 Notion 或 Wiki。
