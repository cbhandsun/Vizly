## 官方资料对照

- [yFiles Edge Routing](https://docs.yworks.com/yfiles-html/dguide/polyline_router/) 分别建模节点净距、边间距、端段长度、单调性和局部更新范围。这支持将净距与折点作为不同维度检查，也支持只修改有问题的路径。该工具的“preferred”距离不是本项目 48px 硬门禁的放宽依据。
- [ELK Layered](https://eclipse.dev/elk/reference/algorithms/org-eclipse-elk-layered.html) 描述层次方向、正交端口约束及跨层级连接支持。这适用于比较布局与端口语义；“尽量同向”不代表反馈环可以反转业务边，也不保证域内紧凑和全局阶段顺序能同时最优。
- 同组泳道等宽/等高来自本项目明确要求，不是上述资料推导出的行业通则。是否采用更紧凑的视觉风格属于偏好；不能覆盖业务边语义、净距和泳道尺寸约束。
